# Security policy

## Reporting a vulnerability

Please report security problems privately through this repository's
**Security** tab, using **Report a vulnerability** (GitHub private
vulnerability reporting). Do not open a public issue for a security problem.

A report is acknowledged within 7 days.

## Supported versions

Only the current `main` branch is supported.

## Scope

In scope:

- the SharpLadder site
- this repository

Out of scope:

- third-party systems
- load testing or denial-of-service testing
